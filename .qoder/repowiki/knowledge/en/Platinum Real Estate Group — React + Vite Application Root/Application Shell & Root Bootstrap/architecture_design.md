The module is the entry point of the React SPA. `src/main.tsx` renders the root via `react-dom/client`, wrapping `<App />` in `StrictMode` and `BrowserRouter` from `react-router-dom`. `src/App.tsx` is the single source of truth for global UI state: it owns `theme` (`ThemeMode`), `activeTab` (`NavTab`), `selectedProperty`, project filter, and two modal payloads (`brochureModalProperty`, `scheduleModalProperty`). It composes the shell by rendering `Header`, a `Routes` block with `AnimatePresence`/`motion` transitions for page switches (Home, Projects, Legacy, Contact, Commercial), `Footer`, and `BrochureModal`/`ScheduleModal`. Routing is declarative via `react-router-dom` with a catch-all redirect to `/`. Theme switching toggles a `.dark` class on `document.documentElement` and sets Tailwind utility classes on `body`, which drives CSS variables defined in `src/index.css`. Shared domain shapes (`ThemeMode`, `NavTab`, `HeroSlide`, `Property`, `ScheduleVisitForm`, `RequestBrochureForm`) are centralized in `src/types.ts` and imported by both the shell and child components, keeping type contracts at the root.
