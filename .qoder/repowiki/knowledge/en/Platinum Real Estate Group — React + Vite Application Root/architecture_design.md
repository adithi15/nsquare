The root acts as the build and environment orchestrator for the SPA: `vite.config.ts` composes the `@vitejs/plugin-react` and `@tailwindcss/vite` plugins, registers an `@/*` path alias pointing to the project root, and exposes HMR toggling via `DISABLE_HMR`. `tsconfig.json` mirrors this alias with `paths` so type-checking and IDE resolution match runtime imports. `tailwind.config.cjs` centralizes the brand palette (gold/gold-light/gold-dark) consumed by every page component. `package.json` declares the unified dependency surface (React 19, react-router-dom 7, motion, lucide-react, express, @google/genai) and scripts (`dev`, `build`, `preview`, `clean`, `lint`). `metadata.json` publishes the app identity and capabilities consumed by the hosting/runtime layer. The `app_shell` child is the only entry point compiled from this root configuration, mounting routing, theme, navigation state, and modals that all other pages consume.
